避坑导购 · 云函数代理版（2026-11-07）
================================================

这一版解决了真机报错：request:fail url not in domain list。
原因：小程序直连 api.deepseek.com 时，手机微信会强制校验 request 合法域名；
开发者工具关闭了校验，所以电脑能跑、手机不能跑。

现在改成：
手机 → wx.cloud.callFunction('aiFallback') → 云函数在腾讯云请求 DeepSeek → 结果回传
云函数调用不受 request 域名白名单限制，手机也能正常出卡。


一、部署（只需做一次）
------------------------------------------------
1. 微信开发者工具打开本目录，AppID 为 wx798448025439a338
2. 右键 cloudfunctions/aiFallback → 上传并部署：云端安装依赖
3. 云开发控制台 → 云函数 → aiFallback → 配置 → 环境变量：
     LLM_API_KEY = 你的 DeepSeek Key（必填）
     LLM_BASE_URL = https://api.deepseek.com/v1（可不填，默认就是这个）
     LLM_MODEL = deepseek-flash（可不填）
     SEARCH_API_KEY = 搜索 API Key（查口碑用，可不填）
     SEARCH_PROVIDER = serper / tavily / bocha / brave（可不填，默认 serper）
   同一页把「超时时间」调到 30 秒
4. 回到开发者工具，编译 → 预览 → 手机扫码

注意：Key 只放云函数环境变量，不要写回小程序代码。


二、验证是否成功
------------------------------------------------
1. 首页输入「想买个初音未来手办，300以内」→ 等 10-15 秒
2. 正常出决策卡 = 云函数通了
3. 如果出现「AI 开小差了」，卡片上会显示：
     错误码 E_XXX
     具体原因（原始报错）


三、错误码对照
------------------------------------------------
E_AUTH    云函数环境变量 LLM_API_KEY 没配或填错
E_TIMEOUT 云函数请求 DeepSeek 超时（把云函数超时调到 30 秒，或换 deepseek-chat）
E_RATE    上游限流，稍等再试
E_QUOTA   上游余额/额度不足
E_PARSE   模型输出不是合法 JSON，重试一次通常就好
E_NET     云函数没部署、环境 ID 不对、或云开发没开通
E_UNKNOWN 其他错误，看卡片上的原始报错


四、代码里对应的开关
------------------------------------------------

（手机端仍会因域名被拦而失败，仅用于电脑上快速看 UI）


五、常见问题
------------------------------------------------
1. 云函数部署后仍报 E_NET
   · 确认云环境 ID 与当前 AppID 属于同一个账号
   · 云开发控制台里能看到 aiFallback 这个函数
2. 首次调用慢 2-3 秒
   · 云函数冷启动，正常现象
3. 演示模式
   · 首页点「演示回放」是本地样例，不调模型、不耗额度
   · 再提交真实问题前先退出演示模式

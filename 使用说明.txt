避坑导购 · 队友预览版（2026-11-07）
================================================

这是一个"导进来就能跑"的版本：不绑 AppID、不用开通云开发、不用配任何环境变量。
模型走直连（智谱 glm 免费模型），第一次点击约 5-10 秒出卡。


一、怎么打开（3 步）
------------------------------------------------
1. 微信开发者工具 → 导入项目 → 目录选到本文件夹（含 project.config.json 这一层）
2. AppID 那一栏会显示"游客模式"，直接点确定，不要改成自己的 AppID
   （改成自己的也能跑，但云开发相关的自检按钮会提示未启用）
3. 编译。首页出现输入框和 4 个快捷标签就说明加载成功

已预置的工程配置：
  · 不校验合法域名（urlCheck=false）—— 不开这个会报"不在以下 request 合法域名列表中"
  · libVersion=3.15.1（稳定版，不是灰度版）
  · 没有任何 npm 依赖，不需要"构建 npm"


二、怎么看到效果（最快路径）
------------------------------------------------
点第一个快捷标签「想买台笔记本电脑」→ 等 5-10 秒 → 出决策卡
卡片上应该有：首选/备选方案、价格区间、3 条以内红线、搜索关键词
点卡片下方「查口碑」→ 再等 5-8 秒 → 出真实联网检索的口碑（这个会花 0.01 元/次）

其他能点的：
  · 自己打字提交，例如「初音手办 300以内」
  · 底部「我的档案」→ 保存过的卡片（存本机）
  · 长按底部版本号 v1.0.0 → 开发自检页（能看当前通道、模型链、埋点）


三、控制台里这些"红字/黄字"不用管
------------------------------------------------
· [aiClient] adapter = http · model = ...   → 正常，说明走的是直连模型
· [aiClient] http ok glm-xxx 第 1 枪        → 正常，说明这一枪就出卡了
· The resource ... was preloaded ...        → 开发者工具自己的提示，真机没有
· 正在使用灰度中的基础库 3.x                  → 可在 详情→本地设置 换稳定版，换不换都行
· wx.cloud 相关的一律不该出现；出现了说明改坏了，回退本包

万一出现"该模型当前访问量过大（1305）"：正常现象，代码会自动换备用模型，
你只会觉得慢一点，不会失败。三个备用模型都免费。


四、两个容易踩的坑（提前说）
------------------------------------------------
1）首页最下面「没想好？看个完整示例 →」进的是**本地回放**，不调模型。
   点过之后，再打字提交也是回放（存在本机，重启还在）。
   想回到真 AI：回首页点「退出演示模式」。
2）"查口碑"用的是智谱的联网检索工具，按次计费 0.01 元/次（模型本身免费）。
   账户没钱时不会报错崩掉，会自动降级成"基于模型自身知识"的回答。


五、这个包和你手上开发版的差别（只改了 3 处）
------------------------------------------------
1. appid 改成 touristappid，任何人导入都能开，不需要被加进小程序成员
2. 云开发整包关闭（config.js 的 PREVIEW_NO_CLOUD=true）：
   出卡不依赖云；内容安全、云函数兜底自动跳过，因此不会有 -601034 报错
3. 模型顺序调整（llm.js）：实测 glm-4.7-flash 当时全平台排队（单请求 45 秒不回），
   所以把 0.6-1 秒就回的 glm-4-flash-250414 放首位，4.7 排到链尾。
   等 4.7 恢复了，把 models 数组改回它打头即可，其他代码不用动。

没有改：页面结构、组件、样式、文案、品类枚举、schema 校验、埋点。


六、注意（给项目负责人看）
------------------------------------------------
services/llm.js 里带着 API Key，属于前端直连演示版，解包就能看到。
只适合内部评审/答辩演示，不要公开发布；上线前要切 mode='proxy' 并把 Key 挪到云函数环境变量。
